STEP 3a (sensory pass core), everything behind a new flag FX3 = /[?&]fx=3(?:&|$)/.test(location.search). Without ?fx=3 the game must behave exactly as today (no new calls run, no new nodes in the audio graph).
1) New file src/fx3.js exporting createFx3({ camera, audio }) -> fx with:
   - fx.kick(kind, strength): camera shake as a sum of decaying kicks. Kinds and caps: 'shot' (player fires, pitch up ~0.25 deg + tiny yaw jitter, decay 12/s), 'impact' (nearby round hits within 3 m or a near miss, ~0.4 deg random, decay 9/s), 'blast' (grenade, scaled by 1 - d/12 m, up to ~2.5 deg rotation + 4 cm position, decay 4/s). Total rotation clamped to 3 deg, position to 6 cm. Decay uses exp(-k*dt) so it is framerate-independent; noise is a sum of two sines per axis with random phases sampled from accumulated time (no per-frame Math.random jitter, so at 1 fps it doesn't pop). Reduce-shake: localStorage 'ss.reduceShake' === '1' or ?shake=0 scales everything by 0.3.
   - fx.update(dt) advances; fx.offsets() returns { pitch, yaw, roll, x, y } in radians/metres.
   - fx.blast(pos): kick('blast') by distance from camera, and if d < 10 m calls audio.muffle(strength) with strength = 1 - d/10.
   - fx.nearMiss(point): kick('impact', 0.6) and audio.whizz?.(point) if audio has it (do not create whizz here).
   - window.SS.fx3 = { kicks: count, last: {kind, t}, muffle: current 0..1 } for tests.
2) src/audio.js: add muffle(strength): a BiquadFilter lowpass inserted between master and destination ONLY when FX3 (create lazily on first muffle; keep it in the chain afterwards at 20 kHz). On muffle: frequency ramps to 300 + 900*(1-strength) Hz within 0.05 s, then exponential recovery back to 20000 Hz over 1.2 + 1.6*strength s; plus a ring: sine 3.2-4 kHz, gain 0.05*strength, fading out over the same recovery time, routed AROUND the lowpass (to the destination) so it reads as tinnitus. Expose audio.muffleLevel() (0..1 from the current filter frequency) and add muffle to the returned api.
3) src/main.js: if FX3, create fx after audio and camera exist (window.SS.fx = fx); in simStep call fx.update(dt); in applyCamera, after the existing rotation lines, add fx.offsets() (rotation.x += pitch, rotation.y += yaw, rotation.z = roll, position x/y offsets added after the eye height line and removed before the next frame's position logic, so the walk and cover code never see shaken positions). Use rg -n "function applyCamera|createAudio|weapon.fire|function simStep" to find spots. Player shot: wherever the player's weapon actually fires a round (rg -n "fire\(" src/weapon.js src/main.js; pick the single place a round leaves), call fx.kick('shot', 1).
4) src/enemies.js: grenade detonation (rg -n "n.landed && n.t >= n.fuse") -> window.SS.fx && window.SS.fx.blast(n.m.position). In enemyShoot, for rounds that MISS the player, compute the closest approach of the tracer segment to the camera; if < 1.5 m call window.SS.fx && window.SS.fx.nearMiss(closestPoint). Do not change hit chance, damage or the shot path.
