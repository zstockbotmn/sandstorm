STEP 3b (behind FX3 = /[?&]fx=3(?:&|$)/ in src/audio.js; src/fx3.js and audio.muffle exist from 3a, read them first with rg -n). Without ?fx=3 nothing changes.
1) Player breathing (synth, no samples): band-passed noise (centre ~700 Hz, Q 0.8) shaped into inhale (0.9 s rise) / exhale (1.1 s fall) cycles. Rate and level follow an effort value E in 0..1: E = max(lowHp, exertion), lowHp = clamp((45 - health)/35, 0, 1) from window.SS.player.health, exertion rises by 0.35 on each cover move (window.SS.cover state change in/out, rg -n "cover.state" src/main.js src/cover.js) and by 0.5/s while sprinting if a sprint flag exists, decaying at 0.12/s. At E < 0.15 silent. Rate 14 -> 34 breaths/min, gain 0 -> 0.07. Below 25 HP also a heartbeat: two low sine thumps (55 Hz, 60 ms, 0.18 s apart) at 70 -> 120 bpm.
2) Footsteps while window.SS.walking && running: one short gravel crunch per step (noise burst, lowpass 1.8 kHz, 70 ms, gain 0.035 +-20%, alternating slight pan +-0.15), step interval = stride 0.72 m / walk speed (rg -n "SPEED" src/main.js; read it via window.SS if exposed, else add window.SS.walkSpeed = SPEED in main.js). No steps while crouched in cover or stopped.
3) Schedule in audio.update(dt) using the AudioContext clock (lookahead 0.1 s), never more than 2 voices per frame, so 1 fps doesn't burst. Expose audio.fx3State() -> { effort, breathsPerMin, steps } and set window.SS.fx3Audio to it each update.
node --check src/audio.js src/main.js and node tools/build.js at the end.
