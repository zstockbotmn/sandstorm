STEP 3e1 (behind ?fx=3 only): a cheap post look as a NEW file src/post3.js plus 3 lines in src/main.js. Do not read big files whole: rg -n "FX3|createFx3|applyCamera|function frame" src/main.js, and read only those lines.
1) src/post3.js exports createPost3({ renderer }) returning { update(dt) }. It creates ONE fixed full-screen div (pointer-events:none, z-index just above the canvas but below the HUD: put it right after renderer.domElement in the DOM) with two layers: a radial-gradient vignette (transparent centre -> rgba(20,12,4,0.55) corners), a warm grade tint (background rgba(255,190,120,0.06), mix-blend-mode: soft-light if supported) and a grain layer (a 64x64 noise CanvasTexture-like image made once with canvas.toDataURL, background-repeat, opacity 0.06, its background-position jumped to a random offset at most 12 times per second).
2) Drive: hurt = clamp((45 - window.SS.player.health) / 35, 0, 1); blast = window.SS.fx3 && window.SS.fx3.muffle || 0. Vignette opacity 0.55 + 0.4*max(hurt, blast); when hurt > 0 add a red edge (a second radial gradient rgba(140,0,0,0.5*hurt)). If CSS backdrop-filter is supported (CSS.supports('backdrop-filter','grayscale(1)') or the -webkit- form) apply grayscale(0.6*hurt) blur(2*blast px) on a separate layer, else nothing extra. Only touch style properties when a value changed by > 0.02 (no per-frame style churn).
3) Auto-off: keep a 2 s moving average of frame rate from update(dt) wall time (performance.now deltas, not dt). Under 24 fps for 3 s straight -> hide the grain and grade layers (keep only the static vignette, which costs nothing), postOff = true; back on after 6 s above 30 fps. Ultra-low (window.SS.quality === 'ultra-low', checked every update) -> hide everything.
4) window.SS.fx3.post = { mode: 'overlay' | 'none', postOff, hurt, blast, grain: visible bool } updated each update.
5) main.js: import createPost3; where createFx3 is created under FX3, also create post3 = createPost3({ renderer }); call post3.update(dt) once per rendered frame next to the existing fx.update call (rg -n "fx.update" src/main.js).
node --check src/post3.js src/main.js at the end. Do NOT run node tools/build.js.
