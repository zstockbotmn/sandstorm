Critically-damped springs for per-bone hit reactions, no per-frame allocation (module-level temp vectors/quaternions).
export function createReactState() -> { arm: {x,v}, spine: {x,v}, buckle: {x,v}, zone: null, side: 1, dir: new THREE.Vector3(), stepLeft: 0, stepDir: new THREE.Vector3(), w: 0 }.
export function kickReact(st, zone, dir, rightWorld) : zone in 'armL'|'armR'|'legL'|'legR'|'torso'. st.zone = zone; st.dir.copy(dir) with y=0, normalized (fallback (0,0,1)); st.side = zone ends with 'L' ? -1 : zone ends with 'R' ? 1 : (sign of dir.dot(rightWorld)||1). Impulses are added to the spring VELOCITY so repeated hits stack but clamp each x to its peak: arm v += 9 (peak x 0.55 rad); spine v += zone==='torso' ? 5.5 : 2 (peak 0.30 rad); buckle v += zone.startsWith('leg') ? 5 : 0 (peak 1.0 = full buckle). torso: st.stepLeft = 0.3 + Math.random()*0.1 (m), st.stepDir.copy(st.dir). leg: st.stepLeft = 0.18 (sideways stumble), st.stepDir = horizontal perpendicular of dir toward st.side.
export function stepReact(st, dt) : clamp dt to [0, 0.1]; sub-step in slices of <= 1/60 s; each spring x'' = -2*w*v - w*w*x with w = 22 rad/s for arm/spine and 14 for buckle (semi-implicit Euler: v += a*h; x += v*h), clamp x to its peak. Root step: move = min(st.stepLeft, dt * (st.stepLeft > 0 ? 0.9 : 0)) per call, st.stepLeft -= move; return the move distance (m) so the caller moves the group along st.stepDir. st.w = clamp(max(|arm.x|/0.55, |spine.x|/0.30, buckle.x), 0, 1). When all |x|,|v| < 1e-3 and stepLeft <= 0: zero them and st.zone = null.
export function applyReact(st, bones, bendBone, upWorld, rightWorld, fwdWorld, level) : level 2 = full, 1 = spine flinch only, 0 = nothing. bones are THREE.Bone by Mixamo-like names (Spine, Spine01, Spine02, LeftArm, LeftForeArm, RightArm, RightForeArm, LeftUpLeg, LeftLeg, RightUpLeg, RightLeg, Hips; any may be missing - skip). bendBone(bone, worldAxis, angle) premultiplies a world-axis rotation (provided by caller). Bullet axis: _ax = normalize(cross(upWorld, st.dir)) (bending about it tips the top of a bone along the bullet). Spine (level >= 1): bendBone(Spine01||Spine, _ax, spine.x*0.6) and (Spine02||Spine) the remaining 0.4, plus a twist bendBone(Spine01||Spine, upWorld, -st.side*spine.x*0.25). Level 2 only: arm zone -> hit side ('L' = Left*, 'R' = Right*) UpperArm bendBone(*Arm, _ax, arm.x) and ForeArm bendBone(*ForeArm, _ax, arm.x*0.6). Leg zone -> buckle b = buckle.x: hit-side UpLeg bendBone(*UpLeg, rightWorld, -0.35*b), *Leg bendBone(*Leg, rightWorld, 0.7*b). Return hipDrop = level===2 ? 0.09*buckle.x + 0.03*Math.abs(spine.x)/0.3 : 0 (m, caller lowers the model root).
