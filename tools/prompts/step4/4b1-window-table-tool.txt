STEP 4b1 (offline tool, no game code): a NEW node script tools/window-table.mjs that finds the painted window openings on the Meshy street facades and writes assets/models/windows.json. Read only: rg -n "bldg[1-4]" src/art.js | head; ls assets/models/bldg*.glb; and the first 30 lines of tools/lod-uv.mjs (for how this repo loads GLBs in node with @gltf-transform/core and sharp). Do not read other files.
Method per building (bldg1..bldg4, full .glb, not .lod.glb): load with @gltf-transform/core NodeIO (+ KHRONOS_EXTENSIONS and the meshopt decoder from 'meshoptimizer' if the file uses EXT_meshopt_compression, as lod-uv.mjs does), take every primitive's POSITION, TEXCOORD_0 and indices (apply node world matrices), the baseColor texture image decoded with sharp to raw RGBA (apply KHR_texture_transform offset/scale if present). The street face: placeArtBuilding in src/world.js turns the model by +-90 deg about Y, so the street face is one of the model's horizontal sides; do not guess which: test all four (+X, -X, +Z, -Z), keep the one whose ray hits are nearest to its bbox face on average and that has the most dark window texels, record it as "face" in the json and print it.
On that face cast a grid of rays (u along the face every 0.25 m, v up every 0.25 m, from 0.6 m to the top) into the mesh (plain JS ray-triangle, Moller-Trumbore, over all triangles; a few hundred thousand tests per building is fine offline). For each hit take the texel colour at the hit UV: a window cell is dark (luma < 0.22) or glass-blue-grey (low saturation, luma < 0.35) AND the hit is within 0.35 m of the face plane's median depth (not a balcony gap). Group 4-connected window cells into rects; keep rects 0.5-2.2 m wide and 0.7-2.4 m tall with fill ratio > 0.6; shrink each by 0.06 m per side.
Output assets/models/windows.json: { "bldg1": { "face": "+X"|..., "size": [sx, sy, sz] (model-space bbox), "windows": [ { "u": 0..1 along the face (left to right seen from the street), "v": 0..1 up, "w": metres_model_space, "h": metres_model_space, "depth": metres behind the face plane } ] }, ... } and print a per-building count. Also write logs/windows-<name>.png: the face's texture-hit colour grid with the rects outlined (sharp), so a human can check them.
Do NOT run the game, tests or browsers. Do run: node --check tools/window-table.mjs. Do NOT run the tool itself (it runs after the tester). Do NOT git commit.
