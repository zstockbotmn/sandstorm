1) src/interior.js exports:
 a) createInteriorAtlas(): a 512x256 canvas, 4 cols x 2 rows of 128x128 cells, painted once, cached, returned as a THREE.CanvasTexture (SRGBColorSpace, ClampToEdge, mipmaps on, anisotropy 1). Each cell is a "projected room" image: the back wall is the centred rectangle at BACK = 0.5 of the cell size; the floor, ceiling and left/right walls are the four trapezoids between the back wall and the cell edge (perspective room seen straight on). Desert palette, simple flat shapes with a little gradient: plaster walls (cream, ochre, pale blue, faded green), tiled or rug floors, a darker ceiling, a back doorway or a shelf or a framed picture or a table/chair silhouette per cell, one cell with half-drawn curtains, two cells shuttered/dark (very dark interior, slats). Add a soft darkening toward the back wall (depth).
 b) createInteriorMaterial({ atlas, cols = 4, rows = 2, back = 0.5 }): a THREE.ShaderMaterial for an InstancedMesh of PlaneGeometry(1, 1) quads (quad local +Z faces the street / the viewer; local X width, Y height). Per-instance attributes: aRoom (float, atlas cell 0..7), aLit (float 0..1, a warm lamp glow), aSize (vec2 quad width/height in metres, so the room depth looks right on any size). Vertex: world position from modelMatrix * instanceMatrix; the view ray in the quad's own axes = dot((worldPos - cameraPosition), each normalized column of the (modelMatrix * instanceMatrix) 3x3), so no matrix inverse is needed. Fragment: classic box interior mapping: ray from the window point p = (uv*2-1, 0) into a box x,y in [-1,1], z in [0,-1] scaled by room depth = 0.9 * aSize.x (in units of the half-width), find the nearest wall hit, depth fraction d in [0,1], then convert the hit to the single-image coords: q = hit.xy / mix(1.0, 1.0/back, d) * 0.5 + 0.5 and sample the cell (inset 1.5 texels against bleeding). Then: lit rooms add a warm gradient (aLit * vec3(1.0,0.75,0.45) * 0.6 * (1-d)), unlit rooms scale by 0.55; glass: mix in a pale sky tint by a cheap fresnel (pow(1-|viewZ|, 3) * 0.35) and a faint dirt mottle from the uv. Support scene fog (fog: true, include the fog_pars and fog_fragment chunks and UniformsLib.fog) so far windows melt into the haze. One texture fetch per pixel. precision mediump; it must compile on iPhone Safari WebGL2 (GLSL3 via three.js, no derivatives extension needed).
 c) createInteriorFallback({ atlas, cols, rows }): Ultra-low flat version, a MeshBasicMaterial-based onBeforeCompile (or a tiny ShaderMaterial) that just shows the atlas cell flat (same instance attributes), no ray.
 d) buildWindowMesh(list, material): list of { pos: Vector3 (centre of the window opening on the street face), normal: Vector3 (street-facing, horizontal), w, h, room, lit }; returns one THREE.InstancedMesh (PlaneGeometry(1,1), count = list.length) with instanceMatrix = translate(pos + normal*0.02) * rotation (+Z to normal) * scale(w, h, 1) and the InstancedBufferAttributes above; frustumCulled false is NOT wanted: compute a bounding sphere from the list (mesh.geometry is shared, so set mesh.boundingSphere / override computeBoundingSphere, three r15x InstancedMesh supports computeBoundingSphere()). castShadow false, receiveShadow false, userData.ownGeo = true only if the geometry is not shared (share one PlaneGeometry module-wide and do not dispose it).
