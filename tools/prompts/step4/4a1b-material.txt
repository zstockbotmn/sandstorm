Export createInteriorMaterial({ atlas, cols = ATLAS_COLS, rows = ATLAS_ROWS, back = ATLAS_BACK } = {}): a THREE.ShaderMaterial (fog: true, uniforms = THREE.UniformsUtils.merge([THREE.UniformsLib.fog, { uAtlas: { value: null }, uGrid: { value: new THREE.Vector2(cols, rows) }, uBack: { value: back } }]) then set uniforms.uAtlas.value = atlas) for an InstancedMesh of PlaneGeometry(1, 1). Per-instance attributes (declared in the vertex shader): attribute float aRoom; attribute float aLit; attribute vec2 aSize;
Vertex: mat4 m = modelMatrix * instanceMatrix; vec4 wp = m * vec4(position, 1.0); vec3 v = wp.xyz - cameraPosition; vView = vec3(dot(v, normalize(m[0].xyz)), dot(v, normalize(m[1].xyz)), dot(v, normalize(m[2].xyz))); vUv = uv; vRoom = aRoom; vLit = aLit; vSize = aSize; vec4 mv = viewMatrix * wp; gl_Position = projectionMatrix * mv; plus #include <fog_pars_vertex> at the top and, after mv, the line `vec4 mvPosition = mv;` followed by #include <fog_vertex>.
Fragment (#include <common> not needed; precision is set by three): #include <fog_pars_fragment>. Room box in window units: x,y in [-1,1], depth D = 1.8 * vSize.x / vSize.y... keep it simple: scale the ray so x spans the half-width: vec3 rd = normalize(vec3(vView.x / (0.5 * vSize.x), vView.y / (0.5 * vSize.y), vView.z / (0.9 * vSize.x))); ro = vec3(vUv * 2.0 - 1.0, 0.0); rd.z is negative into the room (the quad's +Z faces the viewer, the camera is on +Z, so vView.z < 0 for a visible pixel). t to the side walls: tx = (sign(rd.x) - ro.x) / rd.x (guard rd.x ~ 0 with a large value), same for ty, back wall tz = (-1.0 - ro.z) / rd.z; t = min(tx, ty, tz); vec3 h = ro + rd * t; float d = clamp(-h.z, 0.0, 1.0). Single-image coords: vec2 q = h.xy / mix(1.0, 1.0 / uBack, d) * 0.5 + 0.5; clamp q to [0.012, 0.988] (bleed inset).
